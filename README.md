# 구구단 레이싱

곱셈을 잘 맞혀야 이기는 아이용 레이싱 게임. 트랙을 3바퀴 돌아 1등으로 들어오면 승리한다.

**<https://racing.wetipapa.com>**

## 실행

```bash
open index.html
```

빌드도 설치도 없다. 정적 HTML/CSS/JS 세 파일이 전부다.
GitHub Pages로 배포되며 `CNAME`이 커스텀 도메인을 잡는다.

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조, 시작·설정·게임 방법 UI |
| `game.js` | 게임 로직 전체 (캐릭터, 맵, 아이템, 물리, AI) |
| `style.css` | 스타일 |

## 게임

**× 상자**를 지나면 곱셈 문제가 나온다. 정답이면 부스터로 빨라지고, 틀리면 크게 느려진다.
**? 상자**에서는 아이템을 얻는다 (최대 3개 보관). 바나나·로켓·방패·번개 등.

| 설정 | 값 |
|---|---|
| 트랙 | 햇살 공원(쉬움) · 사탕 마을(보통) · 우주 정거장(어려움) |
| 캐릭터 | 블레이즈 · 노바 · 불도그 · 코멧 · 럭키 · 교수 (능력치가 조금씩 다름) |
| 구구단 | **2~9단을 개별로 선택.** 자주 쓰는 조합은 단축 버튼(2·3단 / 4·5단 / 6·7단 / 8·9단 / 전체) |
| 모드 | 🐢 이지(제한시간 넉넉) · 🔥 하드(5초 제한) |

조작은 `←` `→` 또는 `A` `D`, 모바일은 화면 아래 버튼. 아이템 칸을 누르면 사용한다.

## 고칠 때

주요 상수는 `game.js` 위쪽에 모여 있다.

```js
TOTAL_LAPS = 3            // 바퀴 수
QUESTION_TIME = 5         // 하드모드 제한시간(초)
EASY_QUESTION_TIME = 18   // 이지모드 제한시간(초)
BOOST_DURATION = 2.4      // 정답 부스터 지속시간
WRONG_SLOW_FACTOR = 0.32  // 오답 시 속도 배율
```

- **캐릭터 추가** — `CHARACTERS` 배열에 항목 하나 추가
- **맵 추가** — `MAPS` 배열에 항목 하나 추가. 상자는 `boxLayout`에 위치만 적으면
  트랙 폭에 맞춰 4개가 자동으로 깔린다. 별도 클래스는 필요 없다

## 화면 원칙

첫 화면은 **바로 시작** 버튼이 먼저 오고, 트랙·캐릭터·구구단·모드 설정은
`설정 바꾸기`로 접혀 있다. 게임 방법도 아래쪽 보조 영역이다.
7세 아이가 설명을 읽기 전에 시작할 수 있어야 하므로, 이 순서를 뒤집지 않는다.

상위 `../CLAUDE.md`에 웨티파파 프로젝트 공통 규칙이 있다 (이 저장소에는 포함되지 않음).
